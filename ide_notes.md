# Заметки о работе с Git в VS Code

## 3 вещи, которые удобны в VS Code:
1. Визуальное отображение изменений (diff) — сразу видно, что добавил или удалил
2. Удобная панель Source Control — можно делать commit, push, pull без команд
3. GitLens показывает, кто и когда изменял каждую строку кода

## 1 вещь, которую удобнее делать в терминале:
- Сложные операции (rebase, cherry-pick, reset) — в терминале больше контроля и видимости процесса
